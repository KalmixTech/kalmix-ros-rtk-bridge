# Security Policy

## Reporting a vulnerability

Do not create a public issue for a suspected vulnerability or for exposed credentials. Send a minimal, redacted report to [service@kalmixtech.com](mailto:service@kalmixtech.com) and identify the report as relating to KALMIX ROS 2 RTK Bridge.

Remove NTRIP usernames and passwords, caster host names, serial identifiers, IP addresses, exact coordinates, NMEA records, RTCM files, and full operation logs before sharing any material.

## Supported releases

Security fixes are evaluated for the current published release branch. The release notes identify the supported version and known limitations.

## Credential exposure

If a credential appears in a commit, issue, pull request, screenshot, CI log, or local log archive, revoke or rotate it at the service provider immediately. Removing a file or rewriting a branch does not make an already exposed credential safe.
